## ⚡ Quick start

1. Add the marketplace and install the plugin, see [Installation](docs/en/installation.md).
2. Call `/plugin-v0:meeting-tasks` and name your notes file or paste the text.
3. Check the list and the target path, then say yes.

## 🛠 Features

### :meeting-tasks

Turns meeting notes into a task list. What the notes do not say stays "open". It saves only after your yes.
