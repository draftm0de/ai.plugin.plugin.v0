A skill is comparable to a work instruction for an employee.

It describes how the AI assistant is to carry out a certain task, which rules apply and which steps must be followed.

Plugin V0 comes with the following skills, one per task. In Claude Code you call them by their name. In Codex and ChatGPT you describe the task or pick the skill.

## 📖 Skills

### meeting-tasks

`/plugin-v0`

You give the skill your meeting notes and get a task list: description, owner and due date. What the notes do not say is not made up but marked as "open". It reads text you paste or a file ending in `.txt`, `.md` or `.markdown`. It does not read audio, PDF or Word, and it sends nothing to other task tools.
