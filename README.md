Aus deinen Meeting-Notizen wird eine Aufgabenliste mit verantwortlicher Person und Termin. Du siehst sie zuerst und speicherst sie erst nach deinem Ja als CSV-Datei.

Lizenz: MIT. Siehe [Lizenzentscheidung](docs/license.md).

## ⚡ Schnellstart

1. Füge den Marketplace hinzu und installiere das Plugin, siehe [Installation](docs/de/installation.md).
2. Rufe `/plugin-v0:meeting-tasks` auf und nenne deine Notizdatei oder füge den Text ein.
3. Prüfe die Liste und den Zielpfad und sage Ja.

## 🛠 Features

### :meeting-tasks

Macht aus Meeting-Notizen eine Aufgabenliste. Was nicht dasteht, bleibt „offen“. Gespeichert wird erst nach deinem Ja.
